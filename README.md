# LinguaAI · AI English Coach

LinguaAI 是一个面向数字媒体科技作品竞赛展示的纯前端网站 Demo，模拟基于生成式人工智能的个性化英语学习助手。

## 项目结构

```text
codex-test/
├── index.html    # 页面结构、各功能视图和模拟登录弹窗
├── styles.css    # 深色科技感 UI、响应式布局、动画和组件样式
├── app.js        # 路由切换、聊天、作文分析、学习计划和提示交互
├── favicon.svg   # LinguaAI 浏览器图标
└── README.md     # 项目说明与运行方式
```

## 本地运行

项目不依赖 Node、构建工具或后端服务，直接使用任意静态文件服务器即可。

### 方式一：Python

```bash
cd codex-test
python3 -m http.server 4173
```

浏览器打开 <http://localhost:4173>。

### 方式二：Node

如果已经安装 `npx`，可以运行：

```bash
cd codex-test
npx serve . -l 4173
```

## Demo 展示路径

1. 首页点击“开始今天的学习”，进入 AI 口语陪练。
2. 在聊天框输入英文，查看模拟 AI 回复、语法评价、发音建议和评分变化。
3. 进入 AI 作文批改，输入作文或直接点击分析，查看原文、修改版本和词汇升级。
4. 进入智能学习计划，选择水平、目标和每日时间，生成个性化计划。
5. 进入学习数据，展示学习天数、词汇、口语评分、折线趋势和学习组成。
6. 点击右上角头像或侧边栏“退出登录”，查看模拟登录界面。

## 说明

- 所有 AI 回复、评分、分析和统计数据均为前端模拟数据，方便竞赛现场稳定演示。
- 页面采用原生 HTML、CSS 和 JavaScript，后续可以将 `app.js` 中的模拟函数替换为真实 API 调用。
- 移动端通过左上角菜单按钮打开导航栏，适合电脑、平板和手机展示。
